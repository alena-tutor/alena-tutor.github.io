# WordPet — Google + GitHub

Игра для повторения слов с питомцем. Рабочие данные находятся в закрытой Google-таблице. Этот каталог содержит код, рисунок и искусственные тестовые данные. Ученические ключи, глоссарии, записи уроков и идентификаторы закрытых Google-проектов сюда не загружаются. Конфигурация передаётся через WORDPET_CONFIG_JSON в GitHub Secrets.

## Статус

Версия исходников — 1.7.0. [Последние запуски публикации](https://github.com/alena-tutor/alena-tutor.github.io/actions/workflows/wordpet.yml) показывают фактически установленную версию Google. Код в main публикуется после успешных проверок. При отзыве разрешения Google потребуется повторное [подключение](SETUP.md).

В 1.7.0 слова, выражения и примеры проигрываются из заранее подготовленных британских нейрозаписей Emma (Kokoro). Голос устройства и внешний словарный поиск в игре не используются. Записи закрыты в Google Drive; API проверяет ученика и слово до чтения файла. Новая лексика попадает в закрытую очередь при синхронизации глоссариев и сохранении слова; GitHub Actions каждый час готовит только недостающие записи. Приватная очередь и аудио не публикуются в репозитории, артефактах или логах. Источники модели и лицензии: SPEECH-LICENSES.md.

В 1.6.0 примеры употребления выделяются в словаре, перед тренировкой и после ответа: английское предложение, перевод и короткая подсказка по сочетаниям. В таблице Слова добавлены поля exampleRu и usage после прежних 14 столбцов. Старые данные совместимы; предыдущие снимки тренировки дополняются контекстом только при совпадении примера. Кабинет преподавателя позволяет редактировать пример, перевод и подсказку. Частный словарь остаётся в Google, в коде только общие учебные примеры.

В 1.5.0 добавлены сборка слова/выражения из букв и пропуск с выбором английского слова. Для уже освоенной лексики (два правильных ответа подряд без вариантов) пропуск даётся без списка. Ключ проверяет форму, подходящую именно к авторскому примеру; значение на русском снимает неоднозначность. Пропуски без подходящего примера заменяются вводом слова. Сохраняются 10 оцениваемых заданий, повторение ошибок, награды и история. Новые типы появляются в новых тренировках; незавершённая старая миссия продолжается по прежнему плану.



В 1.4.1 восстановлен webapp в манифесте Google. Проверка опубликованного кода теперь учитывает манифест, а отдельная HTTP-проверка открывает страницу без личных ключей и проверяет ответ WordPet.

В 1.4.0 ежедневная миссия содержит 10 автоматически проверяемых заданий: перевод, ввод слова, прослушивание с вводом, пропуск и восстановление авторского примера из частей. Новые голосовые и свободные письменные ответы не создаются. Незавершённые прежние миссии заменяют неотвеченные ручные задания практикой без изменения первоначального процента и награды. Старые ответы сохраняются. Если подходящего примера нет, сборка заменяется вводом английского слова.

В 1.3.0 добавлен выбор лисёнка, котёнка, щенка или дракончика в ученическом профиле. Вид и имя сохраняются в существующей записи питомца; опыт, монеты, корм, аксессуары, словарь и история сохраняются. Набор дополнительных разрешений Google не меняется. Иллюстрации встроены в приложение и не требуют отдельного хранилища для каждого ученика. 

В 1.2.0 добавлены список выбранных слов перед тренировкой, «Не знаю» с повторением до правильного ответа, публикация через GitHub Actions и архивирование старой истории.

## Хранение

- Слова обновляются по постоянному идентификатору ученика и английского слова.
- Прогресс обновляется по ученику, слову и навыку; новая строка на каждое повторение не создаётся.
- Питомец и награды хранятся отдельно от тренировок.
- Тренировки старше 180 дней, у которых нет непроверенных ответов, копируются в закрытые JSON.gz-архивы в Google Drive по годам. Одна операция обрабатывает до 100 тренировок.
- Перед очисткой проверяются реальные сохранённые байты и SHA-256. Операция возобновляется по журналу Архивы; счётчики в Итоги защищены от повторного применения. При ошибке сохранения или проверки исходная история остаётся.
- В кабинете преподавателя доступны ссылки на последние 30 файлов; все файлы остаются в папке WordPet — архив тренировок. Просмотр текста старых предложений выполняется после скачивания и распаковки JSON.gz. Встроенный просмотр архивных предложений и автоматическое восстановление пока не реализованы.
- Тренировки за последние 180 дней и непроверенные ответы сохраняются. Старые брошенные тренировки без ожидающих проверки ответов тоже архивируются. Их объём, рост словарей и заполнение Google Drive всё равно требуют контроля: бесконечного хранилища нет. Автоматическое удаление записей аудио не выполняется.

Текущие слова, прогресс, питомцы и личные ссылки не удаляются архивированием. Аудиофайлы остаются в прежней закрытой папке Google Drive.

## Разработка и публикация

Node.js 20+. `npm ci --ignore-scripts`, `npm run build`, `npm test`. Сборка не требует зависимостей; clasp 3.4.1 с зафиксированным lock-файлом нужен только для публикации.

Workflow `.github/workflows/wordpet.yml` запускается при изменениях `wordpet/`, при PR и вручную. Публикация разрешена только из main после тестов. Секрет Google передаётся через окружение и хранится только во временном закрытом файле, удаляемом после операции. Форки и PR не публикуются. Удалённый HEAD кода заменяется содержимым GitHub; ручные правки в редакторе перед обновлением нужно переносить в репозиторий.

Развертывание обновляется по существующему ID. Перед публикацией проверяются наличие развертывания и исходный код текущей опубликованной версии. Если он уже совпадает со сборкой, повторная загрузка не выполняется. После изменения проверяются фактический номер версии и совпадение опубликованного кода со сборкой; при запаздывании списка развертываний чтение повторяется до пяти раз. Предыдущая версия остаётся в Google, её номер записан в сводке Actions для отката. Проверка через Google API подтверждает публикацию; работа озвучивания и мобильного интерфейса требует проверки на телефоне.
