# Однократное подключение публикации

Статус: код и автоматическая проверка готовы. Для первой публикации ещё требуется разрешение владельца Google-аккаунта. Подключение Google Drive в ChatGPT не даёт разрешения управлять Apps Script через GitHub.

1. Скачай WordPet-Setup.zip из сообщения ChatGPT, распакуй и запусти `WordPet-Setup.cmd` на Windows. Если потребуется Node.js, установи версию LTS с официальной страницы, которую откроет установщик, и запусти файл повторно. Он не устанавливает Node.js самостоятельно.
2. В открывшихся настройках Google включи Google Apps Script API. Вернись в окно настройки и нажми Enter. Войди в Google-аккаунт, которому принадлежит WordPet. Настройщик проверит доступ к существующему проекту.
3. Настройщик скопирует разрешение в буфер и откроет добавление секрета GitHub. Сначала сохраняются настройки проекта с именем `WORDPET_CONFIG_JSON`, затем разрешение с именем `WORDPET_CLASPRC_JSON`. Для каждого поля Secret вставь Ctrl+V и нажми Add secret. Между сохранениями возвращайся в программу и нажимай Enter. Оба значения хранятся в GitHub Secrets, а не в файлах репозитория. Не присылай его в чат. Вернись в окно и нажми Enter.
4. Откроется страница WordPet в GitHub Actions. Нажми Run workflow, оставь Publish включённым и нажми Run workflow. Успешная проверка кода сама по себе не означает публикацию: нужна успешная операция Publish to Google.

После подключения изменения файлов `wordpet/` в `main` проходят сборку и тесты, затем публикуются в существующее развертывание. Ученические ссылки и Google-таблица сохраняются. Если разрешение Google будет отозвано или истечёт, настройщик понадобится снова.

## Восстановление предыдущей версии

В описании успешной публикации записан Previous Google version. Запусти WordPet workflow вручную, укажи этот номер в Rollback Google version. Код обновлять или переносить учеников не требуется.

## Проверка после первой публикации

Открой свою личную ученическую ссылку: перед заданиями должен быть список слов, в заданиях с пропуском — «Не знаю». Перезагрузи страницу после ответа и проверь сохранение. В кабинете преподавателя появится раздел Архив. Автоматическая архивация использует уже настроенный шестичасовой триггер глоссариев; на листах Итоги и Архивы появятся записи, когда тренировки станут старше 180 дней. Непроверенные ответы не архивируются.
