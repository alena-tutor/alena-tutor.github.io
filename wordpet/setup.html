WORDPET
Нужно один раз подключить Google

Обновления игры —
без ручной вставки кода

Слова, прогресс и питомцы остаются в твоём Google. После подключения новые версии будут публиковаться через GitHub.

Скачай WordPet-Setup.zip из сообщения ChatGPT. В нём находятся настройки твоего Google-проекта, поэтому этот архив не опубликован на сайте.

Распакуй архив целиком и запусти WordPet-Setup.cmd. Если Windows показывает предупреждение, исходный код обоих файлов доступен в твоём репозитории.

ШАГ 1

Запусти настройку

Оставь все файлы из архива рядом. Если программа попросит Node.js, установи версию LTS с открывшейся официальной страницы, затем запусти настройку ещё раз.

ШАГ 2

Подключи свой Google

Настройка откроет страницу Google. Включи Google Apps Script API, вернись в окно программы и нажми Enter. Затем войди в аккаунт, которому принадлежит WordPet.

ШАГ 3

Сохрани разрешение в GitHub

Программа скопирует разрешение в буфер и откроет нужную страницу GitHub. Имя секрета: WORDPET_CLASPRC_JSON. Сначала программа предложит сохранить WORDPET_CONFIG_JSON, затем WORDPET_CLASPRC_JSON. Для каждого секрета вставь содержимое буфера в поле Secret с помощью Ctrl+V и нажми Add secret. Между сохранениями возвращайся в программу и нажимай Enter.

Разрешение не нужно отправлять в чат или добавлять в файлы сайта.

Вернись в программу и нажми Enter. На открывшейся странице WordPet нажми Run workflow, оставь Publish включённым и запусти обновление.

Когда всё подключено?

Когда в GitHub успешно завершится «Publish to Google». До этого рабочая игра остаётся на прежней версии.

В обновлённой игре появятся список слов перед заданиями, кнопка «Не знаю» и раздел «Архив» в кабинете преподавателя.
